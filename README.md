# AutoMiner

AutoMiner is a Minecraft plugin designed for Minecraft version 1.8.8. It allows players to auto-mine with a diamond pickaxe (6/3/3), drop items into specified slots, keep 1 item, and run in the background. The plugin is built using Java and Maven, and it is compatible with PaperMC.

## Install

1. Download the AutoMiner plugin JAR file from the [releases page](https://github.com/EnderDevelopment/AutoMiner/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server.

## Use

1. Join your Minecraft server.
2. Hold a diamond pickaxe (6/3/3) in your main hand.
3. Use the command `/automine` to toggle auto-mining on or off.
4. The plugin will automatically mine blocks and drop items into your inventory, keeping 1 item in your hand.
